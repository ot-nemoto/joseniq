# 動きのロジック

攻め手（兵・武将）、守りの武将と守りの兵、櫓・大筒が、だれを狙い、どう動くかをまとめる。数値はどれも仮の値で、`src/sim/defs.ts` にある。作りは `src/sim/battle.ts` の `attackerAct`・`defenderAct`・`towerAct`。

動きを変えるときは、この文書も同じ PR で直す。決めた理由や前の動きは `design.md` の「武将の狙い」に書く。

## 言葉

- **目標**：攻め手が道を進む行き先。本丸（衝車だけは、本丸への道をふさぐ門を先に目指す）
- **寄り道**：攻め手が、道から少し離れた相手に寄って攻めること。寄る相手は、寄り道の距離（`reach`）の内にいる、寄り道の優先の順（`detour`）に並べた種類だけ
- **索敵範囲**：守りの武将が、今いる所から攻め手を見つける距離（`aggro`）
- **戦い始める**：ある相手に、攻撃かスキルを始めること
- **一騎打ち**：武将どうしで戦い始めた状態（`duel`）

## 攻め手（兵・武将）

1. 出撃したら、目標への道を進む。
2. 道を進みながら、0.25秒ごとに周りを見る。今いる所から寄り道の距離の内に、寄り道の優先の順に並べた相手がいれば、前の種類から選んで寄る。同じ種類なら近い者。ただし、壁を壊さずに、寄り道の距離の2倍（`DETOUR_PATH_RATE`）以内の道のりで着ける相手だけ。
   - スキルを出せる番の武将は、スキルが届く相手も、寄り道の距離より遠くても選ぶ（信長の三段撃ちは7マス先、昌幸の火計は8マス先から出す）。
3. 道の上の門にぶつかったら、壊して通る。
4. 相手が射程に入れば攻撃する。スキルを出せる番で、相手がスキルを出す距離に入れば、立ち止まってスキルを出す。
5. 戦い始めたら、その相手が倒れるまで狙いを変えない（`fight`）。優先の高い相手が来ても乗り換えず、道をふさぐ門を壊しているときも、壊し終えるまで寄り道を探さない。例外は2つ。
   - 寄り道で追っている守りの武将が、寄り道を始めた所から寄り道の距離の2倍より遠くへ逃げたら、追うのをやめて道に戻る（スキルが届くあいだは追う）。
   - 武将は、守りの武将が近くに来たら乗り換える（下の「一騎打ち」）。
6. まだ戦い始めていないとき（建物へ歩いているとき）に、2.5マス以内に守りの武将か守りの兵が来たら、そちらへ移って戦う（身を守るため）。
7. 寄った相手を倒したら、また周りを見て、だれもいなければ目標への道に戻る。

### 寄り道の距離と優先の順

| 攻め手           | 寄り道の距離         | 寄り道の優先の順 |
| ---------------- | -------------------- | ---------------- |
| 歩兵             | 3                    | 施設             |
| 工兵             | 6                    | 施設             |
| 弓兵・騎兵・斥候 | 3                    | 武将＞施設       |
| 盾兵             | 1                    | 武将＞施設       |
| 衝車             | 1                    | 門               |
| 武将（7人とも）  | 3（`GENERAL_REACH`） | 武将＞施設＞門   |

施設は弓櫓・鉄砲櫓・大筒・鼓楼・鐘楼。武将は、守りの武将と守りの兵（信玄が呼んだ騎兵）。本丸は目標なので、寄り道の順には入れない。

### 兵だけの動き

- 衝車は、武将や兵を攻撃しない（6の、そばの守りの武将へ移る動きもない）。
- 斥候は攻撃しない囮。寄る相手に近づき、追われたり撃たれたりしたら下がり、下がり終えたらまた近づく。
- 盾兵は、周り1.5マス（`SHIELD_RADIUS`）にいる、武将でない味方の受ける傷を代わりに受ける。

## 守りの武将

1. 置かれた持ち場に立つ。
2. 今いる所から索敵範囲（5マス。`GENERAL_AGGRO`）の内にいる攻め手を探す。スキルを出せる番のあいだは、スキルを出す距離まで広がる（昌幸は8マス、信長は7マス）。
3. 範囲の内では、攻めの武将を兵より先に狙う（`defOrder`。今はどの武将も 武将＞兵）。同じ種類なら近い者。兵を狙っていても、範囲に攻めの武将が入れば武将へ移る（0.25秒ごとに見る）。同じ種類で、今の相手より近い者が来ても乗り換えない。
4. 狙った相手が範囲の内にいるあいだは追う。範囲は追った先の今いる所から測るので、相手が下がり続ければ、持ち場からいくらでも離れてついて行く（つり出し）。
5. 相手が射程に入れば攻撃する。スキルは攻め手と同じ。
6. 範囲の内に攻め手がいなくなれば、持ち場へ歩いて戻る。戻る途中で範囲に攻め手が入れば、また追う。
7. 秀吉は、周りの建物を直し続ける。

### 攻撃の知らせと鐘

範囲の内に攻め手がいなくても、次のときは、今いる所から索敵範囲に8マス（`ALERT_EXTRA`）を足した距離の内の攻め手へ向かう。そのあと3秒（`ALERT_TIME`）は、その距離の内の相手を追う。
- 索敵範囲の内で、味方が攻撃された
- 鐘楼の鐘が鳴った（鐘楼が見つけた攻め手のうち、近い者へ向かう）

## 一騎打ち

攻めの武将と守りの武将が戦い始めたら、どちらかが倒れるまで続く。
- 攻めの武将は、今いる所から寄り道の距離（3マス）の内に守りの武将が来たら、施設や門と戦っている途中でも、優先してその武将へ移る。
- 守りの武将は、索敵範囲（5マス）の内に攻めの武将が来たら、兵と戦っている途中でも、その武将へ移る（上の3）。
- その武将に攻撃かスキルを始めた時に、一騎打ちになる。一騎打ちのあいだは、相手の武将だけを狙い、寄り道で追える遠さや索敵範囲の外へ逃げても追う。
- 相手が倒れたら終わる。相手への道が見つからなくなったときも終わる（攻めの武将は、そのあと3秒（`DUEL_LOST_TIME`）は同じ武将へ乗り換えない）。
- 守りの兵（呼ばれた騎兵）は一騎打ちをしない。

## 守りの兵（信玄が呼んだ騎兵）

- 持ち場は、呼んだ武将の今いる所（武将が倒れたら、倒れた所）。
- 守りの武将と同じく、今いる所から索敵範囲（呼んだ武将と同じ）の内の攻め手を、武将＞兵の順で狙って追う。
- 狙う相手がいなければ、呼んだ武将のそば（1.5マス。`TROOP_FOLLOW`）にいれば動かず、離れていれば武将のそばまで歩く。

## 櫓・大筒

- 撃つたびに、射程の内の攻め手を選び直す。攻めの武将を兵より先に撃つ（`BDEF` の `defOrder`。今はどれも 武将＞兵）。同じ種類なら近い者。
- 大筒は、近く（3.5マス。`minRange`）の攻め手は撃てない。
