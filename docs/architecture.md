# 作り

コードの全体の見取り図。ファイルごとの細かい説明は、各ファイルの先頭のコメントに書いてある。

## 全体

Vite で組む、サーバーのない1ページのアプリ。入口は `src/main.ts` で、`src/ui/app.ts` の `startApp()` を呼ぶだけ。

コードは2つに分かれている。

| フォルダ   | 役目                       | 使ってよいもの                                             |
| ---------- | -------------------------- | ---------------------------------------------------------- |
| `src/sim/` | 配置の決まりと、戦いの計算 | 純粋な TypeScript だけ。DOM・three.js・`window` を使わない |
| `src/ui/`  | 画面・入力・3D の表示      | `src/sim/` と three.js と DOM                              |

`src/sim/` は画面に頼らないので、テスト（vitest、node で動く）や、調整のスクリプト（`scripts/`、Vite の `ssrLoadModule` で `src/sim/index.ts` を読む）から、そのまま動かせる。`src/sim/` から `src/ui/` を読み込まない。

## src/sim：決まりと計算

| ファイル                      | 中身                                                                                                                                                          |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `defs.ts`                     | 盤面の大きさ・時間・兵力などの定数と、施設（`BDEF`）・兵（`ADEF`）・武将（`GENERALS`・`GDEF`）の数値。施設の上限（`LIMITS`）                                  |
| `geometry.ts`                 | マスの番号・範囲の判定（城域・外周・堀の帯）・種から作る乱数（`rngOf`）など                                                                                   |
| `layout.ts`                   | 配置データ（`Layout`）と、置く・動かす・消すの決まり（`place`・`moveBuilding`・`putGeneral`）、配置データの読み込み（`validate`）、開戦できるか（`notReady`） |
| `terrain.ts`                  | 地図の型（平城・平山城・山城）と、種から地形（高さ・川・橋）を作る `makeTerrain`                                                                              |
| `presets.ts`・`presetData.ts` | 編成例の城（「基本（平城）」など）と、攻城の編成例「基本」                                                                                                    |
| `battle.ts`                   | 戦いの状態（`Battle`）と、1コマ進める `step`、兵や武将を出す `deploy`                                                                                         |
| `plan.ts`                     | 攻城の出撃の予定（`Draft`：口と、口ごとの出撃の行）と、その読み書き                                                                                           |
| `auto.ts`                     | 予定を開戦からの秒数で出す `deployDue`、編成例（`TEMPLATES`）を最後まで戦わせる `runPlan` など。調整のスクリプトとテストが使う                                |
| `record.ts`                   | 前の形の出撃記録の読み込み（今の形で読めなかったときの予備）                                                                                                  |
| `index.ts`                    | 上のものをまとめて書き出す（スクリプトの入口）                                                                                                                |

### 戦いの計算の流れ

1. `createBattle(layout)` で、配置データから戦いの状態を作る（施設・守りの武将・本丸・地形）
2. 開戦すると、画面が1コマごとに `deployDue`（予定の出撃）と `step` を呼ぶ。1コマは `DT`（1/30 秒）
3. `step` の中は、櫓が撃つ → 守りの武将が動く → 攻め手が動く → 倒れたものを外す → 効果や記録の時間を進める、の順。本丸が落ちたら、その場で `win` に決まる。`step` の最後で、`TIME_LIMIT` を過ぎていれば `timeout`、攻め手がいなくなり、もう出せる兵も武将もなければ `wipe` に決める
4. 開戦したあとに手で出した兵や武将は、画面が `deploy` で入れる

戦いの計算には乱数を使わない。同じ配置と同じ出撃なら、毎回同じ結果になる。地形だけは乱数を使うが、種から作るので、同じ種なら同じ地形になる。

## src/ui：画面

| ファイル                   | 中身                                                                                                                                                                                                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app.ts`                   | 画面ぜんたいのまとめ役。状態（配置・攻城の予定・戦い・選んでいる道具など）を持ち、パネルを作り、入力を受け、保存し、毎コマ `renderer.draw` を呼ぶ。中は「保存」「パネル生成」「モード切替」「攻城配置」「入力」「居城の移転」「メインループ」などの節に分かれている |
| `renderer.ts`              | 盤面の表示（three.js）。`app.ts` から受け取った `View`（モード・配置・戦い・マウスの下のマス・選んでいる道具など）を、1コマごとに描く。どのマスを指しているかを返す `tileAt` も持つ                                                                                 |

| `terrain3d.ts`             | 地面の立体（高さの段と側面）                                                                                                                                                                                                                                        |
| `models.ts`・`textures.ts` | 建物の立体の形と、模様の貼り絵                                                                                                                                                                                                                                      |
| `pixel.ts`                 | 武将と兵のドット絵（`SPECS`）と家紋（`MON_PIX`）                                                                                                                                                                                                                    |
| `gear.ts`                  | 武将と兵の持ち物の立体（武器・前立て・幟・衝車の丸太）                                                                                                                                                                                                              |
| `motion.ts`                | 前のコマとの差から、歩く・倒れるなどの動きを読み取る                                                                                                                                                                                                                |
| `icons.ts`                 | パネルに出す施設の小さな絵                                                                                                                                                                                                                                          |
| `compare.ts`               | 兵種の画面（数値の表と番付）                                                                                                                                                                                                                                        |
| `tooltip.ts`               | マウスを合わせたときの説明の枠                                                                                                                                                                                                                                      |
| `dom.ts`                   | 要素を id で取る小さな道具                                                                                                                                                                                                                                          |

### 盤面の描き方

- 地面の上の平らなもの（市松・城域・堀・射程の円・影など）は、Canvas 2D で地面の絵に描き、地形の上面に貼る
- 建物は立体（`models.ts`）、武将と兵はドット絵をこちらに向けた板（Sprite）
- 体力のバー・数・矢・斬撃は、盤面の上に重ねた別の canvas に描く

## データと保存

### 配置データ（防衛）

`Layout`（`src/sim/layout.ts`）を、そのまま JSON にしたもの。
- `buildings`：施設の種類と位置（本丸は左上の位置）
- `generals`：守りの武将の種類と位置
- `heights`・`water`・`bridge`：地形（盤面のマスごとの高さ・川・橋。ないときは平らで川なし）
- `map`：地図の型の名前

防衛の「配置データ（JSON）」の書き出しと読み込みで使う。読み込むときは `validate` で確かめ、決まりに合わないものは読み込まない。

### 攻城の出撃の予定（出撃記録）

`Draft`（`src/sim/plan.ts`）を JSON にしたもの。
- `gates`：口の位置
- `rows`：出撃の行。何番目の口から、何を、何体、開戦から何秒に、何秒おきに出すか（武将は1体だけ）

攻城の「出撃記録（JSON）」で使う。戦ったあとに書き出すと、手で出した兵や武将も予定にまとめる。

### ブラウザへの保存

`localStorage` に2つ保存する（`src/ui/app.ts`）。

| 鍵                     | 中身             |
| ---------------------- | ---------------- |
| `kozen-enbu-layout-v8` | 防衛の配置データ |
| `kozen-enbu-siege-v2`  | 攻城の出撃の予定 |

形を変えて前のデータが読めなくなるときは、鍵の末尾の版を上げる。

## テスト

- `src/sim/*.test.ts`：配置の決まり・戦い・出撃の予定・地形を確かめる
- `src/ui/*.test.ts`：画面のうち、DOM なしで確かめられる所（ドット絵・持ち物・動き・カメラ）だけ
- 画面の操作は自動のテストがないので、手で（または Playwright で）確かめる
