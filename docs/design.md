# 方針と決まり

JOSENIQ を作るうえで決めたことをまとめる。動きや決まりを変えるときは、この文書も同じ PR で直す。

## 守る決まり

### 武将の能力は、攻めと守りで同じにする

武将の能力値は、攻める側と守る側でいつも同じにする。釣り合いが崩れても、片方の武将だけを弱めたり強めたりして直すことはしない。釣り合いは、兵種・施設・配置・AI の動き・編成例などで取る。
- 能力値とは、`src/sim/defs.ts` の `GENERALS` に書く値（体力・威力・撃つ間隔・速さ・射程・範囲攻撃・スキルの値（`skillCd`・`skillWindup`・`ward`・`wardTime`・`spin`・`spinRadius`・`skillRange`・`skillShot`・`skillDmg`・`skillPierce`・`skillVolley`・`skillVolleyGap`・`disarm`・`disarmTime`・`disarmRadius`）・火計（`skillFire`・`skillRadius`）・兵を呼ぶ（`summon`・`summonMax`）・火計の燃え続ける傷（`burn`・`burnTime`）などと、`GeneralTraits` の特徴の値）
- 能力値は `GENERALS` に1つだけ書き、守り（`GDEF`）と攻め（`ADEF`）の両方がそれを広げて使う。`GDEF`・`ADEF` の側で、`GENERALS` から来た値を上書きしない（上書きしても型は通る。攻守で値が食い違えば `src/sim/defs.test.ts` が落ちるが、両方で同じ値に上書きしたときは気づけないので、書くときに気をつける）
- `GENERALS` の外にあって、片方の側にしか意味のない値は、能力値ではなく、その側での動かし方の設定。守りの `aggro`（敵を見つける範囲）・`defOrder`（狙う相手の優先の順）と、攻めの `fac`・`gate`・`hall`（施設・門・本丸への倍率）・`pref`（役目）・`detour`（寄り道で狙う相手の優先の順）・`reach`（寄り道の距離）・`cost`・`limit` がこれにあたる。この決まりの外だが、変える前にユーザーに確かめる。攻めの表の `name`・`glyph` は、武将の名前とその1字目を入れる表示のための値で、これも能力値ではない
- 上に挙げていない攻めの値（守将への倍率 `vsGen`、当てた相手を遅くする `slow`、兵を相手にしない `noUnits` など。今は兵の行だけが使う）を武将に持たせるときは、能力値として `GENERALS` に書き、攻守の両方に持たせる

### 武将の新しい特徴は、その武将がいない戦いを変えない

武将に新しい特徴を足すときは、その武将が出ていない戦いの結果が変わらないように入れる。編成例の勝ち負けが変える前と同じかを、`npm run balance` の結果を比べて確かめる。

### 数値は仮

兵種・施設・武将の数値は、今はどれも仮の値。数値の調整は、基盤づくりがひと段落してから行う（下の「進め方」）。仕組みを足したときに釣り合いの実績（`npm run balance` や `npm run balance:combos`）を取るのは、影響を見るためで、その結果からすぐに数値や配置を直すことはしない。

### 城の配置は、現実の城にない形を許さない

開戦前の確かめ（`notReady`）で、現実の城にない形を止める。守りが強すぎる配置は、たいてい現実にない形から生まれるため。
- 櫓・大筒・鼓楼・鐘楼は、本丸から守り手が歩いて行ける所に、縦か横で面していること（`unmannedFacilities`）。現実の櫓は郭の内側から兵が出入りするので、まわりを城壁などで閉じた、だれも入れない櫓はない。閉じた櫓は近くで攻撃する兵に壊されないので、許すと守りが強くなりすぎる
- 門は、縦か横のどちらかの向きで、前後のマスが空いた陸であること（`blockedGates`）。門は人や荷が通る口なので、前後をふさいだ門や、前後が川・堀の門はない。門の前を1マス陸にして、その先に堀を引く形（土橋）は認める
- 塀と郭（`castleShape`）。城は、塀で囲った郭の中に本丸を置き、郭には門から出入りする。本丸への一本道や迷路のように、塀を道の壁として使った城は現実にない
  - 郭は、城壁・門・施設・崖で区切った空き地のひとまとまり。川と堀は、入れるので郭を区切らない（郭は川や堀をまたいで続く）。盤面の外周に出られるものは郭ではなく城の外。施設に面していない、崖だけで閉じた台地は、城と関係のない地形なので郭に数えない。本丸から門をいくつくぐって入れるか（深さ）の順に、二の丸・三の丸…と名前を付ける。本丸を囲まない郭も認め、出丸と呼ぶ。郭の数に上限はない
  - 本丸は塀の中にあること。本丸に（崖をはさまずに）面した空きマスが、門を通らずに外周へつながっていない
  - 城壁・門・櫓は塀の線に置く。塀の線は、縦横斜めの両側が別の郭（または郭と城の外）になる所か、片側が郭でもう片側が崖になる所（崖の上の塀）。野原に置いた城壁や、郭の中に突き出した城壁は塀の線にない。盤面の端まで届く城壁で城の外をいくつかに分けても、どれも同じ城の外なので、その城壁は塀の線にない。川は郭を区切らないので、川に面した所も城壁で囲う（川の向こうが城の外なら、川岸の城壁は郭と城の外の間の塀になる）。塀や本丸と郭の間が崖なら、面していないとみなす
  - 門と櫓は、先に城壁で塀を作り、その城壁の上に置き換えて置く。消すと城壁に戻り、動かすと行き先の城壁と入れ替わる
  - 大筒・鼓楼・鐘楼は、塀の線ではなく郭の中に置く。大筒は壊せば通れる施設なので、塀に組み込むと門の代わりの抜け道になる。幅1マスの郭に置くと郭が分かれる。郭の外（城の外の野原など）にも置けない（`outsideFacilities`）。点数を払う郭がなく、点数を無視して施設を増やせてしまうため。画面で置くときは止めるが、置いたあとで郭を囲む城壁を消したときや、配置記録の読み込みでは生じるので、開戦前の確かめで止める
  - 本丸から城の外へ、同じ門を通らずに行ける道（逃げ道）を `ESCAPE_ROUTES`（2）本作ること。同じ郭の中を通るのは認めるが、途中まででも同じ門を通るのは認めない。現実の城が門を複数持つのは、大手と搦手のように、片方をふさがれても出入りできるようにするため。ゲームでは守り手にとって門は弱点でしかないので、数だけを決めると最小の数を攻めにくい所に寄せる形になる。行き止まりの郭（腰曲輪など）は逃げ道に関係しないので、門1つでも、外の門がなくても作れる。逃げ道は陸だけを通り、川や堀を渡らない（橋は渡れる）。人や荷が出入りする道なので、川や堀で城を囲んだら、橋のかかった所か陸のまま残した所（土橋）から出る
  - 2本の逃げ道の外の門（城の外と城の中の両方に面した門）は、本丸の真ん中から見て `ESCAPE_ANGLE`（90）度以上開いていること（数値は仮）。隣り合わせの門では、片方をふさがれると両方使えないため。内の門どうしの開きは決めない（門どうしの間かくは、下の `GATE_SPACING` で決める）
  - 外の門は、城の外に面した塀 `WALL_PER_GATE`（50）マスにつき1つ（切り上げ）以上置くこと（数値は仮）。塀は城壁・門・櫓のマスで、川に面した城壁も、川の向こうが城の外なら数える。外の門に数えるのは、逃げ道と同じく、攻め手が陸と橋で出撃できる城の外に面した門だけ。まわりを川や堀で囲んだ陸に面した門は数えない（攻め手は必ず水を渡るので、門の前をじかに川や堀にした門と変わらない。前を1マスだけ陸にして、門の前後の決まりを抜けられないようにするため）。門の総数には上限がない
  - 同じ郭の外周の門どうしは、直線で `GATE_SPACING`（15）マス以上離すこと（`closeGates`。数値は仮）。門は、両側の郭のうち本丸に近い（深さの浅い）郭の外周の塀にあるとみなし（同じ深さなら両方の外周にある）、外周の違う門どうし（二の丸の門と三の丸の門など）は比べない。門の数だけを決めると、門を並べて（1マス空けても）数を満たせるが、並んだ門は1つの口と変わらないため。直線で測るのは、塀に沿って遠くても、角をはさんで近い門は一か所から攻められるため。開戦前の確かめでは、郭の土地と点数のあとに見る（郭の形が決まらないと、門の置き場も決まらないため）
  - 郭ごとに、広い土地を `KURUWA_LAND`（100）マス以上取ること。広い土地は、郭の空きマスのうち、`LAND_BLOCK`（3）×3 以上の同じ高さの空き地（川や堀を含まない）の一部になっているマス。郭は人が住み兵が集まる場所なので、幅の狭い通路だけの郭はない
  - 施設は点数で置く（数値は仮）。郭の点数は、広い土地 `LAND_PER_POINT`（10）マスにつき1点。施設の点数は `BDEF` の `cost`（弓櫓2・鉄砲櫓3・大筒3・鼓楼2・鐘楼1）。郭の中の施設は置いた郭が払い、塀の線の櫓は両側の郭のうち本丸に近い（深さの浅い）郭が払う。近さが同じなら、残りの点数が多い郭が払う。点数が足りない所には置けない。施設の種類ごとの数の上限は置かない（数は点数で抑える）。城壁の数の上限も置かない（塀の線・郭ごとの土地と門・仕切ると土地が減ることで抑える）
  - 攻め手が出撃できる城の外は、どこからも城の門（郭に面した門）まで歩いて行けること。城の外だけに面した野原の門に着いても、城へは入れないので数えない。塀で城の外を切り離し、門のない側から攻め手が近づけなくする形は、現実の城を攻める形にない。この確かめでは、川と堀は渡れないものとして数える（橋は渡れる）。戦いでは渡れても、川や堀で城の外を切り離し、門のない側から近づくには必ず水を渡らせる形を止めるため
  - 開戦前の確かめで道を見るとき（外周から本丸への道・城の外から門への道・逃げ道）は、外周の出撃口どうしを歩けないものとして数え、出撃口は、そこから城域へ入る入口としてだけ使う。出撃口づたいに回り込めば門へ行ける、という形を認めないため。外周から本丸への道も、川と堀を渡らずに見る。戦いの中の動きは変えない（攻め手は出撃口を歩け、川と堀を渡れる）
  - 平城では、堀（`moat`）を引ける。効果は川と同じ（下の「川と堀」）。現実の平城の水堀にならい、川から水を引く形だけを許す
    - 堀は、川（またはもう引いた堀）と縦横でつながる、川と同じ高さのマスにだけ引ける（`moatAstray`）。台地の上の城（平山城・山城）には届かないので、堀が効くのは、川と同じ高さの土地が広い平城になる。現実の平城の水堀・山城の空堀の違いにも合う
    - 川に沿って引いて、川を太くしてもよい。塀からの距離も決めない（野原に引いた堀も認める。数の上限で抑える）。前は、川のすぐそばに引く堀（川と並んで走る堀）を止めていたが、決まりが複雑で分かりにくかったので外した。堀で城をぐるりと囲む形は、城の外の野原から陸と橋で門へ行けることと、逃げ道を陸と橋で見ることで止まる
    - 堀のマス数は、城の型ごとに `MOAT_CAP` まで（平城50・平山城0・山城0。数値は仮）。堀は、平城の特徴として川を活かすためのもの。山城や平山城は高低差を活かした戦い方ができるが、平城にはそれがないので、川を活かす堀は平城だけに許す。前は城の広い土地の1割、次に川のマス数の5割にしていたが、山城でも大きな堀を引けたので、型で決めた。郭ごとに分けず、城全体で数える。櫓の点数とは別枠。配置記録を読み込むとき、型の名前が地形の高さと合わなければ、高さから決め直す（平らなら平城、2段までで型が平城か型なしなら平山城、それより高ければ山城）。平城の地形は平らなので、型の名前を書き換えて上限をすり抜けられないようにするため。2段までの山城は、高さだけでは平山城と見分けられないが、堀の上限は同じ
    - 門の前後には引けない（上の `blockedGates`）。ただし、門のすぐ外の1マスに引き、反対側（門の内）が空いた陸なら、その門は引き橋の門になる（下の「引き橋」）。橋の両端にも引けない（下の「橋」）
    - これらの決まりは、引くときには止めず、引いたあとの形で赤く出し、開戦前の確かめで止める。引くときに止めると、塀より先に堀を引けず不便なため（決まりは、開戦するときに満たしていればよい）。引くときに止めるのは、施設・川・堀と重なることだけ
  - 引き橋（`drawbridges`）。門のすぐ外のマスが堀で、反対側が空いた陸なら、その堀のマスは門の引き橋になる。置き物は増やさず、門の前に堀を引くだけで作る。平城は、堀で門の前を守れないと、攻め手がいつも陸づたいに門へ着き、衝車と工兵で門を割る筋が消えなかった（「基本（平城）」を3周探した結果）。施設を強くすると山城・平山城の施設も強くなるので、堀を引ける平城だけに効く仕組みとして足した。現実の平城の引き橋にも合う
    - 開戦前の確かめでは、引き橋を下りた橋（陸）として数える（逃げ道・外周から本丸への道・城の外から門への道・門の前後）
    - 戦いでは上がっていて、ふつうの堀のまま。上がった板が門の外の面をふさぐので、その門に当たるのは、門の中の側の郭（開戦の時に、門の内の隣のマスから、施設と崖をよけて塗った所。大筒のマスと、郭に面したほかの門のマスを含む）から撃った攻撃だけ。引き橋の側や斜め前の陸のほか、塀の外の川や堀から撃っても当たらない（範囲の攻撃も同じ。火計が当たらなければ、門は燃えない）。攻め手は、その門を寄り道の相手にも選ばない
    - 城の中の側から門を壊すと、引き橋が下りて橋になり、ふつうの速さで渡れる。守り手が自分で下ろすことはなく、上がった引き橋へ出ることもない
    - 引き橋にするのは堀だけ。川の前の門は、今までどおり前後がふさがった門。川のある平山城・山城で使えないようにするため
    - 引き橋の門を壁とみなし、引き橋も上げたまま（堀のまま）でも、外周から陸と橋だけで本丸へ行けること（`hallBreachable`）。外の門をすべて引き橋にしたり、内の門をすべて引き橋にしたりすると、攻め手が入れない城になるため。開戦前の確かめでは、門の前後のすぐあとに見る
    - 逃げ道には引き橋の門も数えるので、本丸の郭の門の片方を引き橋にすると、攻め手が本丸へ入る道を1本にでき、その道の上の出丸が廊下になる（本丸を川の向こうの出島に置き、ほかの三方を堀で囲む形など）。堀を引けるのは平城だけなので、これは平城だけの布陣として認める（逃げ道に引き橋を数えないと、引き橋は逃げ道に使わない余りの門をふさぐだけになり、守りが強くならない）。外から引き橋の門を破れる兵種を、別に考えるかもしれない
    - 見た目：防衛配置では下りた橋（数えるときの形）、攻城では、上がっているあいだは門の前に立てた板、門が壊れると下りた橋
  - 両端が門の橋（地形の橋か引き橋）は、2つの門を、郭から郭へ渡る1つの口とみなす。本丸から門を通って入れるかと、郭の深さを数えるときは、この橋を通り、逃げ道もこの橋を通れる。2つの門は外の門に数えない。川は郭を区切らず城の外の野原とひと続きなので、こうしないと、川や堀の向こうに橋でつないだ出島・馬出しが、本丸から入れない郭になるため。現実の城でも、堀の向こうの馬出しを橋で結ぶ形はよくある。戦いの中の動きは変えない（攻め手は川を歩いて橋に上がれる）
  - 橋は渡れること（`bridgeShut`）。橋を渡る向き（左右が陸なら東西、そうでなければ南北）の両端のマスに、門のほかの施設や堀を置かない。橋は人や荷が渡るもので、渡った先をふさいだ橋は現実にない。門は壊せば通れるので置ける。開戦前の確かめでは、門の前後のすぐあとに見る（通り道の決まりなので）
  - 決まりは、盤面で見えないと直し方が分からないので、防衛配置では、郭を色分けして数に入る土地を濃く塗り、塀の線にないもの・点数を超えた施設・郭の外の施設・近すぎる門・橋をふさいだ施設・引けない所の堀・上限を超えた堀（川から遠いものから数える）を赤く、門へ行けない城の外を薄い赤に塗る。パネルには郭ごとの土地・点数と、城全体の逃げ道・外の門の数をいつも出し、堀を引ける型（平城）では堀の数と上限も出す。堀は、施設と同じく絵のボタンで選ぶ（平山城・山城では押せず、「平城のみ」と出す）。門にマウスを合わせると、門の間かく（`GATE_SPACING`）の円を地面に出し、近すぎる門（`closePairs`）の上に赤い丸と距離を出して、合わせた門と赤い点線で結ぶ（線と丸と距離は、城壁に隠れないよう、地面ではなく重ねる絵に描く）。円は、櫓や鼓楼の効果の範囲（軍の色で塗った円）と取り違えないよう、塗らずに白い長めの点線だけにし、門の案内の札に「白い点線：門どうしの間かく」と、近すぎる門までの距離を書く

## 高低の効果

- 射程：射程が2より長いものは、相手より高い所に立つと、高さの差1段につき射程が `HEIGHT_RANGE_BONUS`（1）マス伸びる（数値は仮）。同じ高さや、相手より低い所からは伸びも縮みもしない。見下ろす利点を表すため、立っている高さそのものでは決めない。攻めも守りも同じ決まり。飛び道具でない昌幸の火計も、射程が2より長いので同じように伸びる
- 範囲の円は、同じ高さの相手に届く範囲（もとの射程）を出す。低い相手へ余分に届く分は、円には出ない
- 坂：上りは速さが `UPHILL_SPEED`（0.6）倍。下りは普通
- 崖：隣との差が2段以上なら歩けない。矢や弾は越える

## 川と堀

- 川（橋のかかっていない所）と堀には、兵も武将も、攻めも守りも入れる。中では速さが `RIVER_SPEED`（0.1）倍になる（数値は仮）。兵種ごとの差は付けない。川を通れない線ではなく「渡れば損をする所」にし、橋に回り込むか、遅くなるのを承知で渡るかを選ばせるため
- 川や堀の中にいるあいだは、攻撃もスキルも始めない（攻めも守りも、兵も武将も同じ）。渡り切ってから戦う。高低差の「高い所から撃つと射程が伸びる」と同じく、川にも戦いの効果を持たせ、平城で「川を渡らせて、岸から撃つ」守り方ができるようにするため。道の着く先（攻撃する位置）には水のマスを選ばず、攻め手は、水の中から建物（門・大筒など）へ直に入る道も取らない（水の中では壊せないため）。櫓や大筒は、水の中の相手も撃つ
- 経路は、坂と同じく遅さを見込んで選ぶ（川や堀のマスは、ふつうのマスの `1 / RIVER_SPEED` 倍の重み）。斜めに進むときは、角を挟む2マスのどちらかが川や堀なら通れない（斜めに並んだ水の角を抜けて、水を渡らずに越えないため）
- 矢や弾は越える
- 橋のマスは、ふつうの速さで渡れる
- 川と堀には、施設も武将も置けない
- 見た目：堀は、川と同じ水面にし、岸を明るい切り石で舗装して見分ける。岸の壁を切り石の色にし、陸の側に低い縁石を立て（`terrain3d.ts` の `CURB_HEIGHT`・`CURB_WIDTH`）、地面の絵にも縁石の帯と目地を描く。川の岸は暗い石垣のまま。防衛配置では、決まりに外れた堀は水を張らず、地面の高さで赤く出す（半透明の水面の下では赤い印が見えないため）

## 武将の仕様

- 武将は7人（上杉謙信・大島光義・真田昌幸・武田信玄・織田信長・豊臣秀吉・徳川家康）。前田利家（槍将）と服部半蔵（忍び）は外した。外す前に保存・書き出した配置や出撃の予定に2人がいると、そのデータは読み込めない（前は2人だけを黙って飛ばしていたが、ユーザーの依頼で、飛ばす処理を外した）。武田信玄は馬を降りて軍配を持ち、スキルで騎兵を呼ぶ（下の「武田信玄の騎兵を呼ぶスキル」）。前の通常攻撃の「騎馬の突撃」（狙う向きへ騎馬隊を駆けさせ、帯の中にまとめて当てる）は、仕組みごと外した
- 武将は役目の名前（猛将・弓将など）を持たず、画面にも文書にも武将の名前だけを出す。能力値の表（`GENERALS`）は `busho` だけを持ち、攻め手の表（`ADEF`）の `name` には武将の名前を入れる
- 攻め・守りのそれぞれで、出せる武将は3人まで（`MAX_GENERALS`）。同じ側に同じ武将は1人まで（守りは `LIMITS`、攻めは `ADEF` の `limit: 1`）
- 武将は兵力を使わない（攻めの `cost: 0`）
- 大島光義の「違い矢」（`src/ui/pixel.ts` の `MON_PIX` の `chigaiya`）は、確かな家紋ではなく仮の印

### 武将の基本の値

武将の体力・攻撃・間隔・射程・速さ・スキルの間隔は、能力値の調整を始めるために、ユーザーの依頼で7人とも同じにした（体力2000・攻撃50・間隔0.8秒・射程0.9・速さ1.5・スキルの間隔10秒）。攻めの施設・門・本丸への倍率（`fac`・`gate`・`hall`）も、7人とも1にした（`attackerGeneral` の既定の値）。スキルの効果の値（溜め・射程・傷など）は武将ごとのまま。調整のときに、武将ごとに変える

### 武将の狙い

攻め手・守りの武将・守りの兵・櫓・大筒が、だれを狙い、どう動くかは `docs/behavior.md` にまとめる。ここには、決めたことと理由、前の動きを書く。狙い方の数値と順は仮。
- 守りの武将は、持ち場から離れられる距離（`leash`）を持たず、今いる所から索敵範囲（`aggro`。今は武将一律の `GENERAL_AGGRO`）の内の攻め手を追う。追った先からも同じく見るので、攻め手は守りの武将をつり出せる。前は `leash` の外へは追わなかったが、つり出しを形にするため外した
- 攻めの武将は、兵と同じく本丸への道を進み、寄り道の距離（今は武将一律の `GENERAL_REACH`。歩兵と同じ3）の内の相手に寄る。前は道に関係なく、武将ごとの好み（近い敵・守将・施設）へまっすぐ向かっていた
- 攻めは、目標（道の行き先。本丸、衝車は道をふさぐ門）と、寄り道の優先の順（`ADEF` の `detour`。施設・門・武将から並べる）を分けて持つ。本丸は寄り道の相手ではないので並べない。守り（`GDEF`・`BDEF` の `defOrder`）は武将・兵を並べる。どれも同じ順位（どちらでも近いほう）は作らない。前は兵ごとの好み（`pref`）で寄る相手を決めていて、盾兵は武将と櫓・大筒を同じ順位で選び、弓兵・騎兵・盾兵・斥候は鼓楼・鐘楼に寄らず、櫓・大筒は武将も兵も同じ順位で近い者を撃っていた。厳密な順にそろえたので、武将を出さない攻城の結果も変わった。`pref` は、役目（衝車・武将を好む守りの兵）を表すだけになった（囮の斥候は、のちに外した）
- 攻め手は、戦い始めた相手が倒れるまで狙いを変えない（`Attacker` の `fight`）。前は、施設や本丸を叩いている途中でも、そばに来た守将へ移り、道をふさぐ門を壊している途中でも寄り道を探していた。逃げた守将を追うのは、寄り道で追える遠さまで（どこまでも追うと、攻め手が守りの武将にどこまでもつり出されるため）
- 武将どうしは、近くに来たら優先して狙い、戦い始めたらどちらかが倒れるまで続ける（一騎打ち。`duel`）。近くは、攻めは寄り道の距離、守りは索敵範囲。一騎打ちは、寄り道で追える遠さや索敵範囲の外へ逃げても追う。相手への道が見つからないときだけ終える（門の内へ戻った守りの武将を追えない場面などで、動けなくならないため）
- 守り（守りの武将・守りの兵・櫓・大筒）は、戦っている途中でも、優先の高い相手（攻めの武将）が範囲に入れば乗り換える
- 比較の画面には、狙う相手の優先の順を出さない（動きは `docs/behavior.md` で見る）。武将の表には、寄り道の距離と索敵範囲（守り）を出す。文言は、攻めの相手としての守りの武将も「武将」と書く（前は「守将」）

### スキル

武将は、ふだんは通常攻撃をし、一定の間隔でスキルを出す形に、1人ずつ移していく。今スキルを持つのは徳川家康・上杉謙信・大島光義・織田信長・豊臣秀吉・真田昌幸・武田信玄（下の「徳川家康の軍配」「上杉謙信の回転斬り」「大島光義の弓」「織田信長の三段撃ち」「豊臣秀吉の刀狩」「真田昌幸の火計」「武田信玄の騎兵を呼ぶスキル」）。武将の7人全員が、通常攻撃とスキルを持つ。
- スキルは、攻撃の1回分の番を使う。スキルが出せるようになったら、次の攻撃の番をスキルに替える。攻撃を続けたまま、スキルを演出だけで出す形は採らない（体の動きは一度に1つで、絵と計算が食い違うため）
- 番の中身（攻撃かスキルか）は、前の番を終えた時に決める（`nextSkill`）。次の番が来るまでにスキルが出せるようになっていれば、次の番はスキル。構えの途中で攻撃からスキルに切り替わらない。次の番が来る時刻は、そのときの待ちの減る速さ（守りは鼓楼で速まり、足止めで遅れる）のまま減ると見込む。スキルの溜め（続けて撃つスキルは撃ち終えるまで）は鼓楼で速まらないので、待ちのうち溜めの分は足止めでだけ遅れ、鼓楼で速まるのは効いた時から数える攻撃の間隔だけ
- 戦いが止んで構えを解いたあと（次の番が来られるようになって（攻撃の待ちが0になって）から、`ATTACK_ENGAGED`（1.5秒）を過ぎても番を始めなかったとき）は、構えの絵が出ていないので、番の中身をその時の時刻で決め直す。しばらく戦わなかった武将が、出せるスキルを攻撃の番に使ってしまわないため。最後の攻撃から測らないのは、スキルの長さ・足止め・鼓楼で待ちの長さが変わっても、戦い続けている武将を、しばらく戦わなかった扱いにしないため（前は、最後の攻撃から攻撃の間隔に 1.5秒を足した時間で見ていて、信長の三段撃ちのあとは猶予が0.4秒しかなかった）。画面の構えのコマも、同じ形で構えを解くかを決める
- スキルの値は能力値として `GENERALS` に書き、攻守の両方に持たせる。間隔は `skillCd`（前のスキルを出してから、これだけ経つと次を出せる）、溜めは `skillWindup`。開戦の時点ですぐ出せる
- スキルを出すと、溜めのあとに効き、効いた時から攻撃の間隔（`cd`）を数え直して、次の番から通常攻撃に戻る
- スキルを出した時は、どの武将でも同じく、足元から金の輪と軍の色の輪が広がる（発動の光）。見た目だけで、戦いには関わらない。動きを減らす設定では、輪を広げない
- スキルの溜めのコマでは、武器のまわりを光らせ、武器を目立たせる（絵の `aura`。光の色は、光義の弓・信長の鉄砲・家康の軍配・秀吉の刀が金、謙信の刀が回転斬りの弧と同じ赤み、昌幸の軍配が火計の火の色の赤み、信玄の軍配が白熊の毛の白（同じ軍配の家康の金と見分けるため））。前は体を通る光の柱を立てていたが、武器が目立たないのでやめた。光は絵のない所にだけ置くので、武器が体や兜に重なる所では見えにくい
- 兵種の画面の動作の見本（`src/sim/sample.ts`）には、スキルを持つ武将だけ「スキルだけ」の見本がある。見本の中だけの扱いで、武将の次のスキルを出せる時刻をいつも今にして毎回の番をスキルにし、演出が見えるよう動かず攻撃もしない見本役（光義は矢の通り道の一列、謙信は回転斬りの範囲、家康は味方、秀吉は刀狩の範囲の敵、昌幸は火計の円の内。信玄は呼んだ騎兵が出るのを見せるので、並べない）を並べる。信長の三段撃ちは狙った1人へ撃つので、見本役を並べない。謙信は、寄ってくる道によって範囲に入る見本役が変わるので、見本役と相手がみな範囲に入る所に留める。光義・信長・昌幸は、撃ったあと近づくと遠くから撃つ様子が見えないので、相手をスキルの射程に捉えたらその場に留める（射程の外にいるあいだは歩かせる。守りは、索敵範囲とスキルの射程の外の相手には歩かない）。弓櫓や的を動かすと見本役も一緒に動くので、見本役が盤面の外や建物に掛かる所には動かせない
- 仕組みは武将に共通で、スキルを持たない武将の戦いは変えない。スキルの効果は、武将ごとの値（`ward`・`spin` など）で分ける（`src/sim/battle.ts` の `fireSkill`）
- 絵は、スキルを持つ武将だけがスキルの5コマを持つ。区切りは `src/ui/bigBusho.ts` の `SKILL_TIME` で、溜めの長さが武将ごとに違うので武将ごとに持つ。考え方は攻撃と同じ（前の2コマは次の番までの残りで、後の3コマはスキルを出した時刻から出す）。スキルの動きの長さは、コマの数ではなく溜めの長さで決まる。信長の三段撃ちは、溜めのあいだ前の2コマ目（狙う）を出したままにし（区切りの `hold`）、溜めのあとの3発に後の3コマを1つずつ当てる。秀吉の刀狩も、溜めのあいだ前の2コマ目（掲げる）を出したままにし、効いた時から後の3コマを出す。守りの武将が足止めされて溜め（と撃つ間）が延びたときは、延びた分（`atkLag`。画面のための記録）を、スキルを出してからの経過から引いてコマを選ぶので、効く時刻とコマがずれない。戦いが止んだかの判定（構えを解くか）は、戦いの計算と同じく、次の番が来られるようになってからの経過で見る。4倍速でもどのコマも描画1回分より長く出るので、1倍速で1コマ67ミリ秒ほど、後の3コマで0.2秒ほどが溜めの下限

- スキルを持つ武将は、スキルが出せる番に、相手がスキルを出す距離に入った所で立ち止まってスキルを出す（`src/sim/battle.ts` の `skillReach`）。通常攻撃の届く所まで歩かない。スキルを出す距離は、飛び道具のスキル（光義の弓・信長の三段撃ち）と火計（昌幸）はスキルの射程（`skillRange`。射程で出すスキルかは `rangedSkill`）、回転斬り（謙信）は斬る範囲（`spinRadius`）、軍配（家康）は効く範囲（`WARD_RADIUS`）、刀狩（秀吉）は掛かる範囲（`disarmRadius`）、騎兵を呼ぶ（信玄）はスキルの射程（`skillRange`。高い所でも伸びない）。スキルが効く範囲に敵がいないのに出して、空振りしないため
- 飛び道具のスキルと火計の射程は、2より長いので高い所から伸びる。回転斬り・軍配・刀狩は、効く範囲が高さで変わらないので、出す距離も伸ばさない
- 守りでは、スキルが出せるあいだだけ、狙う遠さを索敵範囲からスキルを出す距離まで広げ、出したあとは元に戻す。索敵範囲の内に相手がいなければ、追わずに持ち場へ戻る
- 飛び道具のスキル（`skillShot`・`skillDmg`）は、溜めが終わった時に狙った相手へ撃ち、ふつうの矢や弾と同じく届いた時に当たる（相手が動けば外れることがある）。溜めのあいだに相手が倒れていたら撃たない。攻めでは、建物に攻めの倍率を掛ける
- 続けて撃つスキル（`skillVolley`・`skillVolleyGap`）は、溜めのあとに1発目を撃ち、撃つ間ごとに残りを撃つ。撃ち終えるまで溜めを続けて動かず、次の番は最後の1発を撃った時から攻撃の間隔のあとに来る（`skillSpan`）

### 大島光義の弓

大島光義は、ふだんは槍で狙った1人を突き、スキルで背負った弓を構えて、遠くまで届く強い矢を1本放つ。
- 通常攻撃は槍で、構える時間（`aim`）は持たない。前の弓の通常攻撃と構える時間（0.36秒）はやめ、その値をスキルの溜め（`skillWindup`、狙う時間）に回した
- スキルの射程は4（弓兵の射程と同じ数で、弓兵の射程を変えても一緒には変えない）
- 矢は貫通する（`skillPierce`）。撃つ時に、狙った相手の動く先を読んだ向きのまま、スキルの射程の端（相手がそれより遠ければ相手の先）まで飛ぶ先を決め、飛びながら通り道の近く（矢の当たる幅 `SHOT_HIT_RADIUS`）にいる敵に1度ずつ当てる。放った所より後ろ（矢の向きと逆の側）の相手には当てない（撃ち手の背中の相手に当たらないため）。傷はどの相手にも同じ。攻めでは、通り道の壊せる建物にも撃った時の攻めの倍率を掛けて当て、建物でも止まらない。矢は塀を越える決まりなので、城壁でも止まらない（城壁は壊れないので傷は入らない）
- 溜めのあいだは、狙った相手へ軍の色の細い点線を引き、溜めが進むほど濃くする
- 貫通の矢は、ふつうの矢より少し長い光の尾を引き、薄い金のにじみと白い芯で光らせる（太く濃くするとビームに見えるので控えめにする）。当たった相手ごとに、当たりの白い輪を出す
- 絵は、待機・歩き・攻撃・被弾・倒れで槍を持ち、弓は背中に斜めに負う。スキルの5コマは、つがえる・引き絞る（前の2コマ）、狙う（溜めのあいだ引き絞ったまま）・放つ（矢が出る時）・下ろす（後の3コマ）。矢は、構えた弓の握りの高さから出す（`BIG_MUZZLE` の弓。武器の表 `SPECS` の `skill` で、スキルで使う武器を決める）

### 織田信長の三段撃ち

織田信長は、ふだんは槍で狙った1人を突き、スキル「三段撃ち」で背負った鉄砲を構え、狙った相手へ3発続けて撃つ。
- 通常攻撃は槍で、構える時間（`aim`）は持たない。前の鉄砲の通常攻撃と構える時間（0.7秒）はやめ、その値をスキルの溜め（`skillWindup`、狙う時間）に回した。構える時間を持つ駒がいなくなったので、構える時間の仕組みごと外した
- スキルの射程は7（鉄砲櫓と同じ数で、鉄砲櫓の射程を変えても一緒には変えない。光義と同じ考え方）。射程に入った所で立ち止まって撃ち、撃ったあとは槍の届く所まで近づく
- 3発は、溜めのあと 0.2秒おきに出る（`skillVolley` 3・`skillVolleyGap` 0.2）。弾はふつうの弾と同じく、飛んでいって届いた時に当たり、攻めでは建物にも攻めの倍率を掛けて当てる。途中で相手が倒れても狙いを移さず、残りの弾は倒れた相手のいた所へ飛ぶ（倒れた相手は動かないので、動く先を読まない）
- 溜めのあいだは、光義と同じく、狙った相手へ軍の色の細い点線を引き、溜めが進むほど濃くする。2発目からは濃いまま
- 絵は、待機・歩き・攻撃・被弾・倒れで槍を持ち（槍の描き方は光義と同じ）、鉄砲は背中に斜めに負う（銃口を左の肩の上に出す）。スキルの5コマは、構える・狙う（前の2コマ。狙うは溜めのあいだも出したまま）、撃つ・撃つ・撃つ（後の3コマ。1発ごとに銃口の火花を出し、反動で少しずつ銃口が上がり、煙が重なる）。弾は肩の高さの銃口から出す（`BIG_MUZZLE` の鉄砲。武器の表 `SPECS` の `skill`）

### 上杉謙信の回転斬り

上杉謙信は、ふだんは刀で狙った1人を斬り、スキル「回転斬り」で周りをまとめて斬る。
- 通常攻撃は範囲攻撃にしない。前は周りの敵にも6割の傷を与えていた（`cleave`）が、周りへの傷は回転斬りだけにした。`cleave` は使う武将がいなくなったので、仕組みごと外した
- 回転斬りは、範囲（`spinRadius`）に敵が入れば、刀の届く所まで歩かずにその場で出す。ただし、相手までまっすぐ歩いて行ける時だけ出し（`straightTouches`。前の騎馬の突撃の帯と同じ確かめ方）、城壁・崖の向こうの相手には出さない（川と堀は歩いて渡れるので、向こうの相手にも出す。川や堀の中にいるあいだは、スキルも出さない）。斬った時は塀を越えて当たるので、塀越しに出すと、塀の外から塀の内の櫓を斬れてしまうため。軍配は傷を与えないので、この確かめをしない（守りでは、塀の外で門を叩く攻め手を見て、門に掛けられる）
- 回転斬りは、短い溜め（`skillWindup`）のあと、足元から範囲（`spinRadius`）の内の敵（武将・兵）に傷（`spin`）を与える。攻めでは、壊せる建物（櫓・大筒・鼓楼・鐘楼・門・本丸）にも、攻めの倍率（`fac`・`gate`・`hall`）を掛けて与える。壊れない城壁には当てない。火計と同じく、塀や崖を挟んでも範囲の内なら当たる
- 溜めのあいだは範囲の円を軍の色で薄く塗り、ふちをなぞる線で残りを示す。斬った時に、白い輪と、少し遅れて金の輪が、範囲のふちへ広がる。溜めのあいだに倒されたら出ない
- 絵のスキルの5コマは、構える・溜める（前の2コマ）、薙ぐ・斬り抜く・残心（後の3コマ）。通常攻撃（頭の上から振り下ろす）と見分けるため、刀はどのコマも胸の下の高さで水平に持ち、横に払う。薙ぐ（手前）と斬り抜く（奥）で、体のまわりに平たい弧を出してひと回りし、斬り抜く・残心では一周の点線の名残を残す。弧（残影）は、通常攻撃の青白い弧と見分けられるよう赤みの色にする

### 徳川家康の軍配

徳川家康は、ふだんは軍配で近くを打ち（射程0.9）、スキルで味方の受ける傷を減らす。風林火山の「山」を元にする。
- スキルは、攻撃の番のうち、スキルが出せる番で出す（上の「スキル」）。軍配の効く範囲（`WARD_RADIUS`）に敵が入れば、軍配の届く所まで歩かずにその場で出す。軍配は自分にも掛かるので、味方がいなくても出す。敵がいない時は出さない（出撃してすぐ出すと、敵に会う前に切れるため）
- スキルの溜め（`skillWindup`）のあいだは金の輪が範囲のふちへ広がり、まだ効かない。輪が届くと、周り（`WARD_RADIUS`）の味方に、受ける傷を `ward` の割合だけ減らす効果を掛ける。守りでは建物にも掛かる（壊れない城壁を除く）
- 攻めでは、ほかの武将と同じ狙い方をする（上の「武将の狙い」）。前は一番近い味方について歩いていたが、近くを打つ攻撃では敵に届かないのでやめた
- 効果が掛かってから、金の円と光の筋を出す。溜めのあいだに出すと、効いているように見えるため。あわせて、金の光の粒が家康から掛かった味方（守りでは建物も）へ飛び、着いた所で金の輪がはじける
- 効果は掛かった相手に付き、`wardTime` のあいだ続く。範囲の外へ出ても、切れるまで続く

### 豊臣秀吉の刀狩

豊臣秀吉は、ふだんは刀で狙った1人を斬り、スキル「刀狩」で周りの敵の与える傷を減らす。家康の軍配（味方の受ける傷を減らす）を、敵に掛ける形にしたもの。特徴の「築城」（守りでは周りの建物を直し、攻めでは周りの工兵を強める）はそのまま持つ。
- スキルは、攻撃の番のうち、スキルが出せる番で出す（上の「スキル」）。掛かる範囲（`disarmRadius`）に敵が入れば、刀の届く所まで歩かずにその場で出す
- 溜め（`skillWindup`）のあと、足元から範囲の内の敵すべて（兵・武将・撃つ施設）に、与える傷を `disarm` の割合だけ減らす効果を掛ける。攻守とも、兵・施設・武将のどれにも掛かる（守りには兵がおらず、施設は守りにしかないので、攻めの秀吉は武将と施設に、守りの秀吉は兵と武将に掛ける）。施設は撃つもの（櫓・大筒）だけに掛け、門・本丸・鼓楼・鐘楼・城壁には掛けない（攻撃しないので、掛けると効いたように見えて紛らわしい）。家康の軍配と同じく傷を与えないので、守りに知らせない（守将を呼び寄せない）。火計や回転斬りと同じく、塀や崖を挟んでも範囲の内なら掛かる。傷を与えないので、軍配と同じく、相手まで歩いて行けるかは確かめない
- 減らすのは、掛かっているあいだに出した攻撃の傷（通常攻撃・スキル・櫓や大筒の弾・火計など、すべて）。傷は、矢や弾を放つ時・斬る時・溜めが終わって効く時に決めるので、掛かる前に放たれて飛んでいる矢や弾は変わらない（`dealtOf`）
- 効果は掛かった相手に付き、`disarmTime` のあいだ続く。範囲の外へ出ても、切れるまで続く。掛け直したら時間を延ばし、割合は重ねない。家康の軍配と重なると、両方の割合が掛け合わさる
- 数値は仮（間隔10秒・溜め0.4秒・範囲3.5マス・4割減らす・4秒）。強さの調整は後で行う
- 溜めのあいだは、謙信の回転斬りと同じく、範囲の円を軍の色で薄く塗り、ふちをなぞる線で残りを示す。効いた時に、軍の色の輪が範囲のふちへ広がり、掛かった相手の所で軍の色の×印がはじける（×印は、動く相手からずれないよう、描く時の相手の位置に出す）。掛かっているあいだは、足元に、掛けた側の軍の色の点線の輪を出す（家康の金の輪の内側）
- 絵のスキルの5コマは、構える・掲げる（前の2コマ。溜めのあいだ掲げたまま、刀が金に光る）、突き立てる・押し込む・残心（後の3コマ）。刀を前の地面に切っ先から突き立て、地面に金の輪を広げる。通常攻撃（振りかぶって斜めに斬り下ろす）と見分けるため、刀はまっすぐ上か、前の地面へ向ける

### 真田昌幸の火計

真田昌幸は、ふだんは家康と同じく軍配で近くを打ち（射程0.9）、スキル「火計」で、離れた所の円の内にまとめて傷を与え、当たった相手を燃やす。前は火計が通常攻撃だった（4秒ごと）が、ほかの武将と同じく「通常攻撃＋スキル」の形にした。狙う相手の選び方は、各武将のスキルの動きができてから見直す。
- 火計は、スキルの番で、狙った相手がスキルの射程（`skillRange`。高い所からは伸びる）に入れば、立ち止まってその場で出す。溜め（`skillWindup`）を始めた時の相手の位置に落ち、溜めのあいだに相手が動いても、落ちる所は変わらない
- 溜めのあと、円（`skillRadius`）の内の相手に傷（`skillDmg`）を与える。攻めでは守将と建物（建物には攻めの倍率）、守りでは攻め手に当たる（攻めは守りに知らせる）。範囲攻撃の火の処理（`blaze`）は、通常攻撃の範囲攻撃と同じものを使う
- スキルが出せないあいだは、ふつうの武将と同じく、軍配の届く所まで敵に近づく
- 当たった相手は燃え、`burnTime` のあいだ、1秒（`BURN_TICK`）ごとに `burn` の傷を受ける（燃え終わる時刻ちょうどの回まで。3秒なら3回）。建物には、火計と同じく攻めの倍率を掛ける。壊れない城壁は燃えない
- 燃えている相手にもう一度当たったら、燃える時間を初めから数え直す。重ねて燃えることはない
- 燃える傷は、ふつうの傷と同じく、家康の軍配で減り、盾兵が代わりに受ける。盾兵が火計の傷を肩代わりしたら、燃えるのも、その傷を肩代わりした盾兵（前から、炎は肩代わりした盾兵に出していたので、炎と燃える傷を受ける者をそろえる）。その傷で盾兵が倒れたら、だれも燃えない。1回の傷は火計が当たった時に決めるので、刀狩が掛かった昌幸の火計なら、燃える傷も減る
- 兵種の画面の1対1では、倒れた時に飛んでいた弾と同じく、残った側が燃えていれば燃え終わるまで決着を待つ（燃えて倒れれば相打ち）。攻城でも、攻め手がいなくなって出撃もできなくなったとき、攻め手が燃やした守将や建物が燃え終わるまで決着を待つ（残りの燃える傷で本丸が落ちれば攻めの勝ち）。作戦の探索や強さの計測が使う自動の進め方（`autoStep`）の全滅の判定も同じ。本丸が落ちて決着したら、燃える傷は入れない
- 炎は、火計を受けた時から燃え終わるまで出す（燃え続ける傷がなければ、前と同じく1.2秒）。燃える傷で倒れても、倒れる動きのあいだ、燃え終わるまで出す
- 数値は仮（軍配は傷50・0.8秒ごと、火計は10秒ごと・溜め0.6秒・射程8・半径2・傷180、燃える傷は1秒に20を3秒）。強さの調整は後で行う
- 溜めのあいだは、前の通常攻撃の火計と同じく、落ちる所に火の色の点線の円を出し、ふちをなぞる線で残りを示す
- 絵の攻撃の5コマは、家康と同じく軍配で打つ（構える・振りかぶる・打ち下ろす・打ち込む・戻す）。スキルの5コマは、前の攻撃の5コマ（構える・掲げる・振り下ろす・指す・下ろす）で、区切りは家康の軍配と同じ。溜めのコマでは、軍配を赤みの火の色に光らせる（同じ軍配の家康の金の光と見分けるため）

### 武田信玄の騎兵を呼ぶスキル

武田信玄は、ふだんは家康・昌幸と同じく軍配で近くを打ち（射程0.9）、スキルでそばに騎兵を呼ぶ。武田の騎馬隊を元にする。前は通常攻撃が「騎馬の突撃」（狙う向きへ、駒ではない騎馬隊を駆けさせ、帯の中にまとめて当てる）だったが、「通常攻撃＋スキル」の形にし、騎馬の突撃は使う武将がいなくなったので仕組みごと外した。
- スキルは、攻撃の番のうち、スキルが出せる番で出す。スキルの射程（`skillRange`）に敵が入れば、その場で出す（高い所でも伸びない）
- 溜め（`skillWindup`）のあと、信玄の足元に騎兵（`summon`）を1体出す。呼んだ騎兵は、ふつうの騎兵と同じ能力値と動きで、倒されるまで残る（信玄が倒れても残る）
- 生きている呼んだ騎兵が上限（`summonMax`）に達しているあいだは、スキルの番にならず、軍配で打つ。1体倒れたら、また呼べる（番の中身は前の番を終えた時に決めるので、倒れた時にもう決まっていた番（軍配）を出してから呼ぶ）
- 呼んだ騎兵は兵力を使わず、出撃の記録・予定・出した数（`used`）に載せない。開戦から2分を過ぎても、最後まで呼べる。全滅の判定では生きている兵として数えず（ほかに兵がおらず、もう出撃できなければ全滅）、倒れても失った数に入れない（呼んだ兵は `summoner` に呼んだ武将の番号を持つ）。倒れても戦況の記録に出さない。作戦の探索や強さの計測が使う自動の進め方（`autoStep`）の全滅の判定も同じ
- 守りの信玄も、同じく騎兵を呼ぶ。呼んだ騎兵は守りの兵（下の「守りの兵」）になる
- 兵種の画面の1対1では、呼んだ騎兵も戦い、与えた傷は信玄の側に数え、決着は信玄本人と相手で決める（決着したら、呼んだ騎兵は去る）。「スキルだけ」などの見本では、呼んだ騎兵は3秒で去る（倒れないので、残すと上限に達して呼ばなくなるため）
- 溜めのあいだは、足元に小さな円（`SUMMON_RING`）を軍の色で薄く塗り、ふちをなぞる線で残りを示す。呼んだ時に、足元から軍の色の輪と土埃が広がる（土埃は駒の上に重なるので、足元の駒を隠さないよう、薄く小さく、足元より外に出す）
- 絵の攻撃の5コマは、家康・昌幸と同じく軍配で打つ。スキルの5コマは、前の攻撃の5コマ（構える・掲げる・振り下ろす・呼ぶ・下ろす）で、区切りは家康・昌幸と同じ。溜めのコマでは、軍配を白熊の毛の白に光らせる
- 数値は仮（軍配は傷50・0.8秒ごと、スキルは10秒ごと・溜め0.6秒・射程6・最大3体）。強さの調整は後で行う

### 守りの兵

守り手は武将と施設で、兵は置かない。守りの兵は、武将がスキルで呼ぶ兵だけ（今は守りの武田信玄の騎兵）。武将の能力は攻守で同じにする決まりなので、守りの信玄も騎兵を呼べるよう足した。
- 守りの兵は、守り手の一覧（`defenders`）に武将と並べて入れる。種類は兵の種類で、呼んだ武将の種類（`leader`）と番号（`summoner`）を持つ。能力値は `defOf` で引く（武将は `GDEF`、兵は兵の能力値（`ADEF`）に、呼んだ武将と同じ見つける範囲（`aggro`）を足したもの）。スキルは持たない
- 持ち場は、呼んだ武将の今いる所（武将が動けば一緒に動き、武将が倒れたら倒れた所に残る）。武将と同じく、今いる所から見つける範囲の内の攻め手を狙って追い、いなくなれば持ち場へ戻る。攻撃の知らせや鐘にも応える。前は呼んだ武将の持ち場（動かない）にしていたが、武将はスキルを出せるあいだ遠くまで出て呼ぶので、呼んだ騎兵がその敵を追えずに持ち場へ戻ってしまった
- 狙う敵がいないときは、呼んだ武将のそば（`TROOP_FOLLOW` の内）にいれば動かず、離れすぎたら武将のそばまで歩く（持ち場のマスそのものを目指すと、武将と同じマスで道が見つからず、武将の上へ跳んで重なるため）
- 狙いは、武将を好む兵（騎兵。`pref: 'general'`）なら、攻めの武将を兵より先にする（武将＞兵）。見つける範囲の内に攻めの武将がいれば、兵を狙っていても武将へ移す（攻め手全体を見るので、狙いがないとき以外は間をおいて見る）。建物は狙わない
- 傷は攻めの兵と同じで、騎兵は攻めの武将に武将への倍率（`vsGen`）を掛ける
- 攻め手からは守将と同じ相手で、狙われ、寄り道の相手にもなる。家康の軍配・鼓楼・弓兵の足止め・刀狩・燃える傷など、守り手への効果も同じく効く
- 倒されるまで残り、呼んだ武将が倒れても残る。倒しても、討ち取った数（`dKilled`）と戦況の記録には入れない。守将の数（`gTotal`）にも数えない
- 画面では、軍の色で兵の絵を出す。マウスを合わせても、武将の札と持ち場の範囲は出さない

### 武将の足し方

1. `src/sim/defs.ts` の型 `GeneralKind` に足す
2. `GENERALS` に能力値を足す
3. `npm run typecheck` が、ほかに足す所（`GDEF`・`ADEF`・`LIMITS`・`SPECS`・`BIG`・説明文など、全員分を求める表）を教えてくれる
4. 型では分からない所は、自分で足す（並び順の配列と `ADEF` の武将の行は `src/sim/defs.test.ts`、家紋は `src/ui/pixel.test.ts` が、入れ忘れを `npm test` で教えてくれる）
   - 並び順の配列 `GENERAL_ORDER`・`UNIT_ORDER`（入れ忘れると、パネルや比較の画面、戦いの判定から黙って抜ける）
   - `ADEF` の武将の行の `general: true`・`limit: 1`（書き忘れると兵として数えられ、人数の上限から外れる）
   - `SPECS` の `mon`（家紋）と、その名前の模様を `MON_PIX` に（書き忘れると幟に家紋が出ない）
5. `npm test` を通し、`npm run balance` の勝ち負けが変わっていないか比べる

## 進め方

### まず基盤、調整は後

いちばん先に、地形などのゲームの仕組みそのもの（基盤）を整える。兵種・武将の数値の調整や、「基本」の城の配置を詰めることは、基盤づくりがひと段落してから行う。仕組みが固まる前に数値を詰めても、仕組みを足すたびにやり直しになるため。

「基本（平城）」の配置と攻城の「基本（平城）」は、ユーザーの依頼で、この例外として詰めた（攻守とも武将なしで、守りと攻めを交互に探した）。「基本（平城）」の城には武将を置かない。配置を探したあとで櫓と大筒の射程を縮めたので、今は攻城の「基本（平城）」で落ちる。武将の射程は変えていないので、武将を出す攻めが有利すぎないかは測っていない。数値や決まりを変えると結果が変わるので、調整のときに見直す。

川を渡れるようにし、川を郭の区切りにしなくしたとき、「基本（平城）」は北を川に任せていたので、川の南岸に城壁を足した。外の塀が長くなった分の外の門（南東 `40,37`）を足し、北東の門を川から1マス南（`40,22`）へずらし、二の丸の広い土地が減って点数を超えた分、北東の弓櫓（`35,22`）を城壁に戻した。探し直してはいない。そのあと、ユーザーの依頼で、守りの強さは見ずに、決まりに合う形に直した。渡れない橋を認めないので、北の橋の出口の城壁を門にし（二の丸へ直に入る門）、門の間かくに合わせて二の丸の西の門を `11,24` から `11,33` へ移した。堀は、西の川の曲がり角 `4,27` から南へ1本（12マス）掘り出し、帯の西の塀の外に沿わせた（南の端の1マスは、堀の西の野原から陸で西の門へ行けるよう陸に残した）。攻城の「基本（平城）」では落ちる（86秒。北の門ができて、前より早い）

### 武将と兵の大きな絵

武将の7人全員（上杉謙信・織田信長・大島光義・真田昌幸・豊臣秀吉・徳川家康・武田信玄）と、兵の6種（歩兵・弓兵・騎兵・衝車・工兵・盾兵）を、動きの多い大きな絵で描く（`src/ui/bigBusho.ts`）。作り方は `docs/development.md` の「武将の大きな絵を作り直す」。下の決まりは、とくに断らないかぎり兵にも当てはめる。ユーザーと決めたこと：
- 3頭身・背丈38ドット（前立てや髷を含む。高い前立てや髷が目印の武将は、40ドットほどまで許す。秀吉の放射状の後立て、家康の歯朶の前立ての輪、信玄の白熊の毛と鍬形は背丈に数えず、頭のまわりに大きく広げる）。絵の枠は 80×72 で、まわりは武器を振る余白
- 兵は武将の半分ほどの大きさで、背丈20ドットほど（陣笠などを含む）。騎兵は28ドット、衝車は26ドットほど。絵の枠は、騎兵と衝車も含めて 56×48。頭は20ドット用に1ドットずつ手で置く。兵は群れで出るので、武将と区別がつくよう簡単にする：顔の部品は描かず肌の面と輪郭だけにし、色は軍の色・黒・肌・木を中心に2段にまとめ、着物・腕・腿は軍の色の暗い段、脚絆と草鞋は黒にする。兵は幟を持たず、前立てや金の飾りも付けない。胴など、兵ごとに決めた所を軍の色に塗る。体力の棒は頭の上の端（`top`）の上に出す。兵ごとの形と攻撃のコマ：
  - 歩兵：陣笠・槍。軍の色は胴・草摺・合印。構える・引く・突く・伸ばす・戻す
  - 弓兵：陣笠・和弓（上が長く下が短い）・背中の矢筒。光義と同じく弓を前へ突き出して引き絞り、矢は引き絞ったときの弓の握りから出す（絵のデータの `muzzle`）。つがえる・引き絞る・放つ・残身・下ろす
  - 騎兵：兜（黒い鉢・眉庇・吹返し・軍の色の縅の錣。前立てなし）・槍で、黒鹿毛の馬に乗る。軍の色は胴・草摺・合印・障泥。馬の胴は前の向き（斜め前は右下、斜め後ろは右上）へ少しだけ傾け、地面も同じだけ傾けて脚の長さをそろえる（前の向きそのものまで傾けると、前脚と後脚の長さがそろって見えない）。枠に収めるため、待機と歩きでは槍を肩に担ぐ。倒れは横へ回さず、馬が膝をついて沈む。構える・引く・突く・伸ばす・戻す
  - 衝車：軍の色の屋根・柱・土台・4つの車輪と、縄で吊るした丸太。左右の幅（丸太が出入りする口）を広めにする。歩きは車輪が回り、倒れは転がらずにその場で潰れる。引く・溜める・突く・打ちつける・戻す
  - 工兵：鉢巻・白木の槌。構える・振りかぶる・打ち下ろす・打ち込む・戻す
  - 盾兵：陣笠・体の高さほどの置盾。軍の色は胴・草摺・合印・盾の帯。盾で押す（構える・引く・押す・押し込む・戻す）
- 描く向きは、斜め前（右前を向く）と斜め後ろ（右後ろを向く）の2つ。左向きは反転して作る。向きによって構える側が入れ替わるのは許容する
- 待機は武器を構えた姿。武器は、どの向きでも画面の左に立てる（謙信は八相・左肩の横、信長は槍を立てて持ち鉄砲を背負う、光義は槍を立てて持ち弓を背負う、昌幸は軍配を立てて持つ、秀吉は謙信と同じ刀の構え、家康と信玄は昌幸と同じく軍配を立てて持つ。家康・昌幸・信玄は攻撃で軍配を振りかぶって打ち下ろし、スキルで軍配を掲げて指す）。斜め後ろでは、体の前にある手と武器の根元を背中に隠す。弓と軍配は、待機では画面の左の手で立て、攻撃では狙う向きの側の手で握るので、向きによって待機と攻撃で持つ手が入れ替わる
- 動きは、各向きに待機4・歩き4・攻撃5・被弾2・倒れ3コマ。スキルを持つ武将は、スキルの5コマも持つ（上の「スキル」）。攻撃は「前の2コマ（次に攻撃できるまでの残りで出す）」と「後の3コマ（攻撃した時刻から出す）」に分け、区切りは `src/ui/bigBusho.ts` の `ATTACK_TIME`。4倍速でも、どのコマも描画1回分（16.7ミリ秒）より長く出る
- どの駒も、攻撃の前に構える時間を持たない（前は鉄砲の信長が構える時間 `aim` を持っていたが、信長の通常攻撃を槍にしたので、仕組みごと外した）。兵の弓兵も、近くで戦う武器と同じく前の2コマを出さずに1回目を撃つ。スキルは、円が出てから効くまでの溜めがすでにある。そのため、どの駒も1回目の攻撃は前の2コマを出さず、後の3コマ（刀なら踏み込み斬り）から始まる。続けて攻撃しているあいだは、前の2コマから出る。まだ攻撃していない武将（開戦前や、持ち場で敵を待つ守り）は、待機の姿のまま。当たる時刻は戦いの計算だけで決まり、絵はそれに合わせてコマを選ぶ
- 武将の頭は38ドット用に1ドットずつ手で置く（縮めた形にしない）。顔は、目を白目と黒目の2ドット（黒目は進む向きの側）、眉を目の上の暗い横線、ひげを髪より明るい茶（白髪の光義は、髪より少し明るい白）、口を赤みの1ドットにして、点が何か分かるようにする
- 細かすぎる模様は減らし、その武将の目印（謙信の白い頭巾と金の前立て、信長の茶筅髷と赤いマント、光義の金の鍬形と長い白髪・白いひげ・背中の矢筒と弓、昌幸の高い金の二本の前立てと赤い緒・生成りの縁の黒い陣羽織・橙の袖、秀吉の放射状の金の後立てと高い黒い兜・赤い鎧・紫の袖・背中の×の紐、家康の歯朶の前立ての輪と赤い鉢巻・白い陣羽織と金の広い襟、信玄の白熊の毛と金の鍬形・武田菱・赤い陣羽織など）を際立たせる
- 敵味方は、背中の幟（家紋と軍の色の帯）で見分ける。朱や赤の飾りも軍の色に塗り替える。幟は字が裏返らないよう反転しない。体力の棒は幟の上に出す
- 防衛と攻城のパネルの武将と兵のボタン（とドラッグ中の絵）と、兵種の画面の表の動きの欄は、大きな絵から全身を等倍（1ドットを画面の1点）で切り出す（`bigBodyBox`）。縮めるとドットが潰れるため。パネルのボタンは横44×縦60ドット（左右の余白を詰め、名前を兵や施設と同じ書き方で1行に出す）、兵種の画面は60ドット四方。パネルでは止まっているときは待機の構え、歩くときは歩きのコマ、兵種の画面では歩き・攻撃・倒れを順に見せる。兵の絵は切り出す枠より低いので、縦は下にそろえて置く。横は、武将と同じく絵の真ん中を切り出す。
- 攻撃の残像は、武器の動きに合わせて絵の側に描く（色は刀の弧と同じ。`scripts/sprites/common.js` の `TRAIL`）。刀（謙信・秀吉）は刀の通った弧、槍（信長・光義）は突く・伸ばすのコマに、穂先から突いた向きと逆へ伸びる細い筋（`thrustTrail`）、軍配で打つ家康・昌幸・信玄は打ち下ろす・打ち込むのコマに、軍配の先の少し外を通る弧（`swingArc`）。軍配で指すスキル（家康・昌幸・信玄）は、打たずに離れた所を指すだけなので付けない。兵は簡単に描く決まりなので付けない。残像は絵のない所にだけ置くので、体や前立てに重なる所では見えない
- 鉄砲の火花と煙は絵の側に描き、弾は肩の高さの銃口から、矢は引き絞った弓の握りの高さから出す（`BIG_MUZZLE`）
- 描いた絵は、まず画像とモーションの確かめのページで見せ、ユーザーの確認を得てからマージする。盤面と確かめのページは同じ表（`bigBusho.ts` の `BIG`）を読むので、確認はブランチの上で行う
