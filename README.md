# JOSENIQ

戦国時代の城を自分で築き、それを自分で攻め落としてみるブラウザのゲーム。

**遊ぶ：https://ot-nemoto.github.io/joseniq/**

インストールは要らない。PC のブラウザで開けばすぐに遊べる。置いた城と出撃の予定はブラウザに保存されるので、閉じても続きから遊べる。

## ゲームの流れ

1. **防衛**で、城を築く。地形を選び、本丸・門・城壁・櫓などの施設と、守りの武将を置く
2. **攻城**で、その城を攻める。兵と武将を、どの口から、いつ出すかを決めて開戦する
3. 時間内に本丸を落とせば **落城**（攻め手の勝ち）。時間切れか、攻め手が全滅すれば **退却**（守り手の勝ち）
4. 結果を見て、守りを固め直すか、攻め方を変えて、もう一度

画面の上のタブで、**防衛**・**攻城**・**兵種**を切り替える。

## 防衛：城を築く

点線の内側（30×30マス）が城域で、ここに施設と武将を置く。
- **置く**：右のパネルで施設や武将を選んでから盤面を押す。または、パネルから盤面へドラッグする。選んだものをもう一度押すと、選ぶのをやめる
- **続けて置く**：城壁と「消去」は、盤面をなぞると続けて置ける・消せる
- **動かす**：置いた施設や武将は、ドラッグで動かせる
- **取り除く**：施設は「消去」を選んでから押す。武将はパネルの赤い枠の武将を押す
- **元に戻す・やり直す**：↶（Ctrl＋Z）と ↷（Ctrl＋Y）
- **全消去**：施設と武将をすべて消す（地形は残る）

### 開戦に必要なもの

- 本丸を1つ
- 門を5つ
- 外周から本丸まで、攻め手が歩いて行ける道（城壁で囲ったら、門で通り道を作る）

足りないときは、パネルの上に理由が出る。

### 施設

| 施設               | 役目                                           |
| ------------------ | ---------------------------------------------- |
| 本丸               | これを落とされると負け                         |
| 門                 | 守りの武将は通れる。攻め手は壊さないと通れない |
| 城壁               | 攻め手は壊せない。門へ回り込ませる             |
| 堀                 | 攻め手の足を鈍らせる（外周から3マス以内だけ）  |
| 拒馬               | 騎兵を止め、ほかの攻め手の足を鈍らせる         |
| 弓櫓・鉄砲櫓・大筒 | 近づいた攻め手を撃つ                           |
| 鼓楼               | まわりの守将と櫓の攻撃を速くする               |

施設には、種類ごとに置ける数の上限がある。川の上には何も置けない。

### 武将

武将は守り・攻めのどちらにも、それぞれ3人まで出せる。猛将・弓将・軍師・槍将・騎馬大将・鉄砲大将・築城名人・忍び・堅守の9人がいて、それぞれ得意なことが違う。何も選んでいないときに、盤面の施設や武将にマウスを合わせると、その情報が出る。

### 地形を変える（居城の移転）

「居城の移転」で、**平城**（平らで川が多い）・**平山城**（なだらかな丘）・**山城**（中央に高い山）から型を選ぶ。押すたびに新しい地形の案が盤面に出るので、気に入ったら「決める」。決めると、置いた施設と武将はすべて消える。

すぐに遊びたいときは、盤面の下の「基本（平城）」などを押すと、見本の城が置かれる。

## 攻城：城を攻める

攻め手の兵力は **60**。兵は種類ごとに兵力を使い（武将は兵力を使わない）、制限時間は **2分30秒**。

### 出撃の予定を立てる

盤面の外周の青いマスが、攻め手の出てくる口。
- パネルから兵や武将を青いマスへドラッグすると、出撃の予定に入る（同じマスに重ねられる）
- 口にマウスを合わせると予定のリストが出る。兵は数・開始（秒）・間隔（秒）を、武将は開始（秒）を変えられる
- 迷ったら、編成例の「基本」を押すと、作戦の見本が置かれる

### 開戦

- 「開戦」で始まり、予定は開戦からの秒数どおりに出撃する
- 開戦したあとも、兵を外周へドラッグすれば（または兵を選んで外周を押せば）、その場ですぐ出せる
- 速度は 1×・2×・4×。スペースキーか「一時停止」で止められる
- 「最初からやり直す」で、開戦前に戻る

### 兵

歩兵・弓兵・騎兵・衝車・工兵・盾兵・斥候の7種類。本丸だけを狙う衝車、櫓などの施設を壊す工兵、まわりの味方の盾になる盾兵、守りを引きつける囮の斥候など、それぞれ役目が違う。

## 兵種：数値を比べる

攻城兵・防御施設・武将の強さを、表と番付で比べられる。表の数値は、戦いの計算でそのまま使っている値。

## 盤面の見方

- 右ドラッグで回し、ホイールで寄る・引く
- 盤面の空いている所をドラッグするか、中ドラッグで見る先を動かす（Shift＋ドラッグでも回せる）
- 「向きを戻す」で、はじめの向きに戻る
- 施設や武将のまわりの薄い円は、敵を見つける範囲

## 配置を残す・渡す

防衛の「配置データ（JSON）」と、攻城の「出撃記録（JSON）」で、城や攻め方を文字にして書き出せる。書き出した文字を読み込めば、別のブラウザでも同じ城や攻め方を再現できる。

## 開発

```sh
npm ci
npm run dev        # http://localhost:5173/
npm run typecheck  # 型チェック
npm run check      # Biome（lint・整形）
npm test           # テスト
npm run build      # out/ に出力（公開先に合わせて base は /joseniq/）
```

- 作業は develop から切ったブランチで行い、develop へ PR を出す。develop に入ると GitHub Pages に公開される
- 毎朝6時（日本時間）に develop から master への PR が自動で出る。含まれる Issue に enhancement があれば `bump:minor`、なければ `bump:patch` のラベルが付き、package.json の版が上がる
- master に入ると、その版でタグとリリースが作られる
