# JOSENIQ

戦国時代の城を自分で築き、それを自分で攻め落としてみるブラウザのゲーム。

**遊ぶ：https://ot-nemoto.github.io/joseniq/**

インストールは要らない。PC のブラウザで開けばすぐに遊べる。置いた城と出撃の予定はブラウザに保存されるので、閉じても続きから遊べる。

## ゲームの流れ

1. **防衛**で、城を築く。地形を選び、本丸・門・城壁・櫓などの施設と、守りの武将を置く
2. **攻城**で、その城を攻める。兵と武将を、どの口から、いつ出すかを決めて開戦する
3. 時間内に本丸を落とせば **落城**（攻め手の勝ち）。時間切れか、攻め手が全滅して、もう出せる兵も武将もなければ（出し切ったか、開戦から2分を過ぎたか） **退却**（守り手の勝ち）
4. 結果を見て、守りを固め直すか、攻め方を変えて、もう一度

画面の上のタブで、**防衛**・**攻城**・**兵種**を切り替える。

## 防衛：城を築く

点線の内側（40×40マス）が城域で、ここに施設と武将を置く。
- **置く**：右のパネルで施設や武将を選んでから盤面を押す。または、パネルから盤面へドラッグする。選んだものをもう一度押すと、選ぶのをやめる
- **続けて置く**：城壁・堀と「消去」は、盤面をなぞると続けて置ける・消せる。Shift を押しながらなぞると、なぞり始めのマスから縦か横の一直線になる（向きは、多く動いた方）
- **動かす**：置いた施設は、何も選んでいないときはドラッグで動かせる（道具を選んでいるときは、長押ししてから動かす）。置いた武将は、いつでもドラッグで動かせる
- **堀を引く**：平城では、施設の「堀」を選んでから、川につながる所を押す（下の「川と堀」）
- **取り除く**：施設と堀は「消去」を選んでから押す。武将はパネルの赤い枠の武将を押す
- **元に戻す・やり直す**：↶（Ctrl＋Z）と ↷（Ctrl＋Y）
- **全消去**：施設と武将と堀をすべて消す（地形は残る）

### 開戦に必要なもの

- 本丸を1つ（2×2マス。盤面の端から5マス以上内側の、段をまたがない平らな所に置く）
- 外周から本丸まで、攻め手が歩いて行ける道。城壁・櫓・鼓楼・鐘楼・崖は通れないので、城壁で囲ったら門で通り道を作る（この確かめでは、川と堀は橋のほかは渡れないものとし、外周の出撃口づたいにも歩かない）
- 門の前後が空いていること。縦か横のどちらかの向きで、門の前と後ろのマスに何も置かない（川や堀でもない。門のすぐ外の堀は引き橋になる）
- 櫓・大筒・鼓楼・鐘楼に守り手が入れること。どれも、本丸から歩いて行ける所（門は通れる）に、縦か横で面して置く。まわりを城壁などで閉じた施設は置けない
- 本丸が塀の中にあること。城壁と門で囲んだ中（郭）に本丸を置く（崖も囲いに使える。川や堀は渡れるので、囲いにならない）。郭は本丸に近い順に二の丸・三の丸…と呼び、本丸を囲まない郭（出丸）も作れる
- 城壁・門・櫓は、郭を囲む塀の線（片側が郭で、反対側が別の郭・城の外・崖になる所）に置く。野原に置いただけの城壁や、郭の中に突き出した城壁は赤く出る
- 本丸から城の外へ、同じ門を通らずに行ける逃げ道を2本作る（同じ郭の中を通るのはよい。逃げ道は川や堀を渡らない。橋は渡れる）。2本の外の門は、本丸から見て90度以上開いた所に置く
- 城の外に面した塀50マスにつき1つ、城の外へ出る門を置く
- 同じ郭を囲む塀の上の門どうしは、15マス以上離す（並べて置いた門は、1つの口と変わらないため）
- 郭ごとに、広い土地を100マス以上取る。郭の空き地のうち、3×3以上の空き地の一部になっているマスだけを数える（幅の狭い通路や、川・堀は数えない）
- 攻め手が出撃できる城の外のどこからも、城の門まで歩いて行けること。川と堀は橋のほかは渡れないものとし、外周の出撃口づたいにも歩かない。塀や川・堀で切り離した、門へ行けない城の外は薄い赤で出る
- 堀（平城だけ）は、川につながる所に、決まった数まで引く（下の「川と堀」）
- 橋を渡れること。橋の両端には、門のほかは置かない（堀も引かない）

防衛配置のとき、郭は色分けされ、パネルに郭ごとの広い土地・点数と、城全体の逃げ道・外の門の数（川のある地形では、堀の数と上限も）が出る。

### 川と堀

川（橋のない所）と堀には、攻め手も守り手も入れるが、とても遅くなる（ふつうの10分の1の速さ）。水の中にいるあいだは、攻撃もスキルも使えず、渡り切ってから戦う。攻め手は、橋が近ければ橋へ回り、遠ければ川を歩いて渡る。渡っているあいだは、岸の櫓や守将から一方的に撃たれる。

堀は、施設の「堀」で引く。堀を引けるのは平城だけ（平山城・山城は、高低差を活かして守る）。
- 川（または引いた堀）に縦横でつながる、川と同じ高さの所にだけ引ける（丘の上の城には引けない）
- 数は50マスまで
- 門の前後と、橋の両端には引けない。門の前を1マス陸に残して、その先に引く（門のすぐ外の1マスだけは、下の引き橋になる）
- 堀の岸は明るい切り石で縁取られ、川と見分けられる
- 川や堀は郭を区切らないので、川に面した所にも城壁が要る
- 引くときは、決まりに外れていても引ける（塀より先に引いてよい）。外れた堀は赤く出て、直すまで開戦できない
- **橋でつないだ出島**：橋の両端をどちらも門にすると、川や堀の向こうの郭（出島・馬出し）も、本丸から門を通って入れる郭に数える
- **引き橋**：門のすぐ外の1マスに堀を引く（門の内は空けておく）と、その門は引き橋の門になる。配置のときは橋として数えるが、戦いでは橋が上がっていて、攻め手は外からその門を壊せない。攻め手が城の中から門を壊すか、鉤縄を持った工兵が外から掛けると、橋が下りる。すべての入口を引き橋にはできず、引き橋の門を通らずに本丸まで行ける道が要る。堀の両側に門を置くと、引き橋は本丸に近い側の門のものになり、反対の門を壊しても橋は下りない（鉤縄はその門を壊した跡から掛ける）

足りないときは、パネルの上に理由が出る。

### 施設

| 施設         | 役目                                                         |
| ------------ | ------------------------------------------------------------ |
| 本丸         | これを落とされると負け                                       |
| 門           | 守りの武将は通れる。攻め手は壊さないと通れない               |
| 城壁         | 攻め手は壊せない。門へ回り込ませる                           |
| 弓櫓・鉄砲櫓 | 近づいた攻め手を撃つ                                         |
| 大筒         | 遠くまで届き、まとめて当てる。すぐ近くは撃てない             |
| 鼓楼         | まわりの守将と櫓・大筒の攻撃を速くする                       |
| 鐘楼         | まわりに攻め手が来ると鐘が鳴り、離れた守りの武将も駆けつける |

鼓楼の効果は重ならない。2つの鼓楼の範囲に入っても、速さは1つのときと同じ。

置ける場所と、使う点数は次のとおり。

| 施設   | 置ける場所       | 点数 | 気をつけること                     |
| ------ | ---------------- | ---- | ---------------------------------- |
| 本丸   | 塀で囲った郭の中 | なし | 1つだけ。2×2マス                   |
| 城壁   | 郭を囲む塀の線   | なし | 数の上限はない                     |
| 門     | 塀の城壁の上     | なし | 前後のマスを空ける                 |
| 弓櫓   | 塀の城壁の上     | 2    | 本丸から歩いて行ける所に面して置く |
| 鉄砲櫓 | 塀の城壁の上     | 3    | 本丸から歩いて行ける所に面して置く |
| 大筒   | 郭の中           | 3    | 本丸から歩いて行ける所に置く       |
| 鼓楼   | 郭の中           | 2    | 本丸から歩いて行ける所に置く       |
| 鐘楼   | 郭の中           | 1    | 本丸から歩いて行ける所に置く       |

門と櫓は、先に城壁で塀を作ってから、その城壁の上に置く（城壁を押すか、城壁へドラッグする）。消すと城壁に戻る。大筒・鼓楼・鐘楼は、塀の線ではなく郭の中に置く。

櫓・大筒・鼓楼・鐘楼は点数で置く。郭は、広い土地10マスにつき1点を持ち、施設を置くとその点数を使う（弓櫓2・鉄砲櫓3・大筒3・鼓楼2・鐘楼1）。塀の上の櫓は、両側の郭のうち本丸に近い郭の点数を使う。点数が足りない所には置けない。施設を選んで盤面にマウスを合わせると、どの郭の点数を使うかが出る。城壁と施設の数に上限はなく、施設は点数の範囲でいくつでも置ける。川の上には何も置けない。

### 武将

武将は守り・攻めのどちらにも、それぞれ3人まで出せる。上杉謙信・大島光義・真田昌幸・武田信玄・織田信長・豊臣秀吉・徳川家康の7人がいて、それぞれ得意なことが違う。何も選んでいないときに、盤面の施設や武将にマウスを合わせると、その情報が出る。

### 地形を変える（居城の移転）

「居城の移転」で、**平城**（平らで川が多い）・**平山城**（なだらかな丘）・**山城**（中央に高い山）から型を選ぶ。押すたびに新しい地形の案が盤面に出るので、気に入ったら「決める」。決めると、置いた施設と武将はすべて消える。「やめる」なら元の地形に戻る。

すぐに遊びたいときは、盤面の下の「基本（平城）」を押すと、見本の城が置かれる。本丸を北の川の向こうの出島に置き、出島の西・北・東を堀で囲んだ城で、守りの武将は置かない。出島の北の門は門の前に堀を引いた引き橋の門で、外からは壊せない。南の門は川の橋で南の郭とつながる。川の南には、二重の塀の郭（出丸）があり、攻め手は南の外の門から出丸を抜けて橋へ向かうか、川を渡って橋に上がる。「基本（平山城）」は、丘の上の台地の縁に外の塀を巡らせた城、「基本（山城）」は、山の段差に沿って二重の塀を巡らせた城で、どちらも武将は置かない。今の城は地形ごと見本に置き換わり、↶ でも戻せないので注意。

高い所は有利になる。射程の長いものは、相手より高い所から攻撃すると、高さの差1段につき射程が1マス伸びる（攻めも守りも同じ。範囲の円は、同じ高さの相手に届く範囲を出す）。坂を上ると遅くなり、2段以上の差は崖で歩いて越えられない。

## 攻城：城を攻める

攻め手の兵力は **60**。兵は種類ごとに兵力を使い（武将は兵力を使わない）、制限時間は **2分30秒**。兵や武将を出せるのは、予定も手で出すのも、開戦から **2分** まで。

### 出撃の予定を立てる

盤面の外周の青いマスが出撃エリア。そこに兵や武将を置いたマスが、攻め手の出てくる口になる。
- パネルから兵や武将を青いマスへドラッグすると、出撃の予定に入る（同じマスに重ねられる）。パネルで選んでから青いマスを押してもよい
- 口にできるのは、辺に沿って両隣2マスまで平地が続くマスだけ。丘や川のそばでは、青くても置けないことがある
- 口の上には、番号の付いた目印が立つ。目印を押すと「軍評定」が開き、全部の口の予定を、縦に兵と武将、横に時間の表で見られる
- 目印をつかんで別の青いマスへ動かすと、その口の兵と武将がまとめて移る。別の口の上で離すと、その口に重なる
- 軍評定では、兵の兵種・数・開始（秒）・間隔（秒）と、武将の開始（秒）を変えられる。数を打ち込むほか、兵の帯をつかんで左右に動かすと開始、帯の右端をつかんで伸び縮みさせると間隔、武将の印をつかんで動かすと開始が変わる。口ごとに兵や武将を足すこともできる
- 工兵の行には、持ち物の鉤縄を持たせられる（1体ごとに兵力6）。行の工兵がそれぞれ1本ずつ持ち、ほかの相手には寄らず、上がった引き橋の外の陸へ向かう。着いたら8秒かけて堀越しに掛け、引き橋を下ろす（門は別に割る）。掛けている途中で倒れると引き橋は下りず、鉤縄も失う。鉤縄を持った工兵だけを別の行にすれば、出す順番や口を決められる
- 予定は開戦から2分まで。兵は、行の最後の1体が2分までに出るように組む（たとえば開始1分50秒・間隔1秒なら11体まで）。数・開始・間隔は、ほかの欄に合わせて入れられる上限が決まる
- 予定から外すには、軍評定の「×」を押す（武将は、パネルの武将をもう一度押してもよい）。攻城の「全消去」で予定をすべて消せる
- 迷ったら、盤面の下の「基本（平城）」「基本（平山城）」「基本（山城）」を押すと、今の予定が作戦の見本に置き換わる（平山城と山城は、同じ名前の見本の城を落とせる作戦。平城は、見本の城を落とせず、川を渡って本丸の手前の門を割るところまでの見本。盤面の城は変わらないので、先に防衛で城を選んでおく。城と合わない作戦を押すと、口がその地形に合わせて動く）

### 開戦

- 経過・残り兵力・開戦・終戦・速度は、盤面の左上のパネルにある。その下の戦況のパネルは、閉じていると最新の1行を出し、押すと古い記録まで見られる
- 再生のマーク（▶）で開戦し、予定は開戦からの秒数どおりに出撃する
- 開戦したあとも、兵や武将を外周へドラッグすれば（または選んで外周を押せば）、その場ですぐ出せる（開戦から2分まで）。武将は、予定に入れていない者だけ
- 速度は 1×・2×・4×。スペースキーか一時停止のマーク（❚❚）で止められ、再生のマーク（▶）で続ける
- 弓・鉄砲・大筒は、矢や弾が飛んでいき、届いた時に当たる。どれも相手の動く先を読んで、その場所へ飛ぶ。まっすぐ進む相手には当たるが、飛んでいるあいだに向きを変えたり下がったりすると外れる。外れた矢は地面に刺さり、大筒の玉は外れた所で弾ける。鉄砲の弾はとても速いので、ほとんど外れない。鉄砲や大筒を撃つと、撃った所に火花と煙が上がる
- 織田信長は、ふだんは槍で1人を突く。一定の間隔で、背負った鉄砲を構えてスキル「国士無双」を出す。鉄砲櫓と同じ遠さまで届き、射程に入ると立ち止まって狙いの点線を引き、狙ってから3発を続けて撃つ。途中で相手が倒れても狙いを移さず、残りの弾は倒れた所へ飛ぶ。攻めでは建物にも当たる
- 大島光義は、ふだんは槍で1人を突く。一定の間隔で、背負った弓を構えてスキルの矢を放つ。弓兵の倍の遠さまで届き、射程に入ると立ち止まって狙いの点線を引き、引き絞ってから射る。矢は狙った相手を貫いて射程の端まで飛び、通り道の敵（攻めでは建物も）すべてに当たる
- 上杉謙信は、ふだんは刀で1人を斬る。一定の間隔で、斬る代わりにスキル「一騎当千」を出す。一騎当千は、範囲に敵が入ればその場で出す。刀を引いて溜めるあいだ、足元に範囲の円が出て、ふちをなぞる線が一周すると、周りの敵と建物をまとめて斬る
- 豊臣秀吉は、ふだんは刀で1人を斬る。一定の間隔で、斬る代わりにスキル「諸行無常」を出す。諸行無常は、範囲に敵が入ればその場で出す。刀を掲げて溜めるあいだ、足元に範囲の円が出て、ふちをなぞる線が一周すると、刀を地面に突き立て、周りの敵（兵・武将・櫓・大筒）に与える傷を減らす効果を掛ける。掛かっている敵の足元には、点線の輪が出る
- 徳川家康は、ふだんは軍配で近くの敵を打つ。一定の間隔で、打つ代わりにスキルで軍配を掲げて振り、金の輪が広がる。軍配は、効く範囲に敵が入ればその場で振る。輪が届くと、中の味方に受ける傷を減らす効果が掛かり、金の円の中に光が立ちのぼる。掛かっている味方の足元には金の輪が出る
- 真田昌幸は、ふだんは軍配で近くの敵を打つ。一定の間隔で、打つ代わりにスキル「煙炎漲天」を出す。煙炎漲天は、射程に敵が入ればその場で出す。構えると落ちる場所に点線の円が出る。ふちをなぞる線が一周すると火が出て、そのとき円の中にいる者に当たる。焼かれた者は、しばらく燃え続け、燃えているあいだ1秒ごとに傷を受ける。燃えている者にもう一度当たると、燃える時間が初めからになる
- 武田信玄は、ふだんは軍配で近くの敵を打つ。一定の間隔で、打つ代わりにスキルを出し、そばに騎兵を1体呼ぶ。呼んだ騎兵は兵力を使わず、ふつうの騎兵と同じく戦う。生きている呼んだ騎兵は3体まで。守りの信玄が呼んだ騎兵は、信玄と一緒に動いて守り、攻めの武将を兵より先に狙う
- 停止のマーク（■）で終戦し、開戦前に戻る

### 兵

歩兵・弓兵・騎兵・衝車・工兵・盾兵の6種類。門を破る衝車、櫓などの施設を壊す工兵、まわりの兵（武将は除く）の盾になる盾兵など、それぞれ役目が違う。兵はどれも本丸への道を進み、道の近くにいる相手にだけ寄り道する（どこまで寄り道するかは兵の種類で違う）。

## 兵種：数値を比べる

攻城兵・防御施設・武将の強さを、表と番付で比べられる。表の数値は、戦いの計算でそのまま使っている値。

名前の欄の右の「動作」を押すと、窓が開いて動作の見本を見られる。選んだ兵・施設・武将が、決まった相手と攻撃し合い続ける（だれも倒れない）。武将は攻めと守りを切り替えられる。盤面をクリックすると、相手の場所を変えられる（施設と守りの武将は的の盾兵がそこへ移り、攻城兵と攻めの武将はそこに弓櫓を置き直し、今いる所からそこへ向かう）。大筒が筒を回したり、武将が向きを変えたりする様子を見られる。速さを 0.25×・0.5× に落とすか、一時停止（スペースキー）で止めると、細かく見られる。窓は ✕ か Esc で閉じる。

スキルを持つ武将（上杉謙信・大島光義・真田昌幸・織田信長・豊臣秀吉・徳川家康・武田信玄）の窓には「スキルだけ」がある。押すと、武将が毎回の番でスキルを出し、まわりに動かない相手や味方が並んで、スキルの演出（光義の矢が並んだ相手を貫く様子、謙信の一騎当千がまとめて当たる様子、信長の国士無双、秀吉の諸行無常が敵に掛かる様子、昌幸の煙炎漲天がまとめて燃やす様子、信玄が騎兵を呼ぶ様子、家康の金城鉄壁が味方に掛かる様子）が見やすくなる。速さを0.25×にすると、演出を追いやすい。

## 盤面の見方

- 右ドラッグで回し、Ctrl＋ホイールで寄る・引く。中ドラッグで見る先を動かす
- 何も選んでいないときは、盤面の空いている所を左ドラッグしても見る先を動かせる（Shift を押しながらだと回す）
- 盤面の右上の方位の針で、北の向きが分かる。針を押すと、はじめの向きに戻る
- 施設や武将にマウスを合わせると、範囲の円が出る。櫓は撃てる範囲（大筒は撃てない近さを点線で示す）、鼓楼は効き目の範囲、鐘楼は見張りの範囲、守将は敵を見つける範囲（薄い円）と射程、持ち場から離れられる範囲（点線）

## 配置を残す・渡す

防衛の「配置記録（JSON）」と、攻城の「出撃記録（JSON）」で、城や攻め方を文字にして書き出せる。書き出した文字を読み込めば、別のブラウザでも、同じ城と同じ出撃の予定を盤面に戻せる。

出撃記録には城が入っていないので、同じ城で読み込む。別の城で読み込むと、口が地形に合わせて近くへ動くことがある。

開戦したあとに手で出した兵や武将は、書き出すときに出撃の予定にまとめる。そのとき出る時刻や場所が少しずれるので、読み込んで戦うと、前の戦いと流れや結果が変わることがある。予定と合わせて兵力や武将の人数を超える分は予定に入らず、書き出すときにその数を知らせる。
